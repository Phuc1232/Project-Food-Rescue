1. KẾT QUẢ
- payment/gateway/PaymentGateway: createLink, getLink(orderCode), cancelLink, verifyWebhook(rawBody) (chữ ký trước, không hợp lệ → InvalidSignatureException).
- PayOsPaymentGateway (java.net.http, không thêm thư viện): POST /v2/payment-requests (orderCode số, amount, description, cancelUrl, returnUrl,
  expiredAt epoch giây, signature HMAC-SHA256 trên amount&cancelUrl&description&orderCode&returnUrl), GET /v2/payment-requests/{orderCode},
  POST /v2/payment-requests/{orderCode}/cancel; header x-client-id, x-api-key; code ≠ "00" → lỗi. Lỗi có kiểu PaymentGatewayException.Kind:
  NOT_CONFIGURED, TIMEOUT, NETWORK, REJECTED, UNAVAILABLE, INVALID_RESPONSE — không chứa khóa.
- PayOsSignature: chữ ký webhook trên data (key sắp xếp, null/"null"/"undefined" → "", mảng/đối tượng → JSON key sắp xếp, không URL-encode, hex),
  so sánh constant-time. Đã khớp vector mẫu tài liệu (checksum key mẫu → 412e915d…eaa03).
- FakePaymentGateway: cùng hợp đồng và thuật toán ký (khóa test cố định), webhookFor(...) sinh webhook đã ký, failNext mô phỏng lỗi; dùng cho test/dev.
- Cấu hình: payment.gateway = fake (mặc định) | payos; prod luôn payos và dừng khởi động nếu thiếu PAYOS_CLIENT_ID/PAYOS_API_KEY/PAYOS_CHECKSUM_KEY;
  payos.base-url, return-url, cancel-url, connect-timeout 5s, read-timeout 10s. .env.example cập nhật (giá trị rỗng). PayOsProperties.toString không in khóa.
- Không endpoint, không migration (OpenAPI không đổi).
