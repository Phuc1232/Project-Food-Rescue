1. KẾT QUẢ
- POST /api/v1/orders/preview {batchId, quantity}: tổng tiền, đơn giá, giá trị cam kết/hộp, cảnh báo, địa chỉ, khung nhận, holdMinutes, chính sách hiện hành
  (phiên bản, tỷ lệ + số tiền giữ lại no-show, giờ phản ánh, điều khoản hủy/hoàn). Không giữ gì.
- POST /api/v1/orders (header Idempotency-Key) {batchId, quantity, acceptedPolicyVersion}: một transaction — khóa account khách → store và sale_batch FOR SHARE
  → chọn N hộp khả dụng FOR UPDATE SKIP LOCKED (hạn an toàn sớm nhất trước) → đủ N mới tạo đơn PENDING_PAYMENT + N box_allocation HELD + hộp RESERVED;
  hold_expires_at = now + orders.hold-minutes (10). Snapshot: giá, tổng, giá trị tối thiểu, cảnh báo (đợt ∪ món của hộp được giữ), địa chỉ, khung nhận,
  phiên bản chính sách + tỷ lệ + giờ phản ánh + điều khoản. Mã đơn FR-yyMMdd-XXXXXX.
- Lỗi 409: NOT_ENOUGH_BOXES (fieldErrors quantity = số khả dụng), BATCH_NOT_OPEN, ORDER_DEADLINE_PASSED, STORE_NOT_ACTIVE, POLICY_CHANGED (fieldErrors =
  phiên bản hiện hành), OWN_STORE, IDEMPOTENCY_KEY_REUSED. Số lượng 1..5. Gửi lại cùng key → 200 cùng đơn.
- GET /api/v1/orders/{orderId}: chỉ khách đặt (khác → 404), dựng hoàn toàn từ snapshot.
- V13: customer_order.idempotency_key + unique (customer_id, idempotency_key). Audit ORDER_CREATED (lịch sử cửa hàng, actorRole CUSTOMER).
