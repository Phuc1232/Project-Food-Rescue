   Kỳ vọng CANCELLED, session OPEN/RECONCILING -> CANCELLED, mã nhận xóa, hoàn PENDING 100% VERIFIED.
   Complete phiên cũ -> 409. Nếu có cancellation request khách đang chờ thì request đó thành APPROVED/storeFault.

   hộp DELIVERED, đơn COMPLETED, inspection FAILED, complaint FOOD_SAFETY OPEN, không tạo nghĩa vụ hoàn thêm.
   Gọi key khác khi complaint còn mở -> POST_DELIVERY_INCIDENT_ALREADY_OPEN.
6) Upload chứng cứ bằng actor hiện tại, gắn attachmentIds. Hộp chưa giao gắn attachment.box;

   Box evidence được owner/BOX_PACK/BOX_MANAGE/ADMIN đọc; complaint evidence được customer/owner/ADMIN đọc.
