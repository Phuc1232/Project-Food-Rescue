2. MÔI TRƯỜNG
macOS 15.7.4 aarch64; Gradle 9.6.0 (wrapper); Docker 29.1.2.
JDK: máy chỉ có 17/24/25; Gradle không tự tải được toolchain 21 trên macOS aarch64
("No defined toolchain download url"). Cách xử lý trên máy này (ngoài repo):
  brew install openjdk@21
  echo 'org.gradle.java.installations.paths=/opt/homebrew/opt/openjdk@21/libexec/openjdk.jdk/Contents/Home' >> ~/.gradle/gradle.properties
(Cask temurin@21 cần sudo nên không dùng.)

4. CHỖ THIẾU / LỆCH (không sửa trong T0)
F1. Thiếu cập nhật hồ sơ cá nhân (UC-06): chỉ có GET /api/v1/accounts/me. → T2.1.
F2. Chưa có seed permission / food_category / financial_policy. StoreAuthorizationTests tự insert permission.
    → seed ở T3.4 (permission), T4.1 (food_category), T4.5 (financial_policy) bằng migration.
F3. Chưa có quản trị tài khoản (UC-68..70) → T3.5.
F4. .env.example: DB_URL dùng cổng 5432 nhưng compose.yml publish 5430; key path ví dụ dạng Windows (C:/...).
    → đề xuất sửa .env.example + README cho macOS/Linux (task tài liệu nhỏ, hoặc gộp vào T2.1).
F5. gradlew lưu trong git với mode 100644 (không executable) → trên macOS phải gọi `sh ./gradlew`.
    → đề xuất `git update-index --chmod=+x CODE/backend/gradlew` (cần cả nhóm đồng ý).
F6. Build phụ thuộc JDK 21 có sẵn trên máy; không có toolchain resolver.
    → đề xuất thêm plugin org.gradle.toolchains.foojay-resolver-convention vào settings.gradle.kts (cần nhóm đồng ý,
    thay đổi build).
F7. Tài liệu chạy local chỉ có lệnh PowerShell; lệnh macOS đã ghi trong CLAUDE.md mục 9 và báo cáo này.
