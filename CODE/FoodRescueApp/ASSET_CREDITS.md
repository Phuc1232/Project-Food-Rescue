## Store map

- Native renderer: [MapLibre Android](https://maplibre.org/maplibre-native/android/), BSD-2-Clause.
- Basemap: [OpenFreeMap Positron](https://openfreemap.org/quick_start/), with application-specific water/park colors.
- Map data: [OpenStreetMap contributors](https://www.openstreetmap.org/copyright), via [OpenMapTiles](https://openmaptiles.org/).
- The map attribution button remains visible above the store card and opens the provider attribution links.
- Price-pin graphics are drawn by the app. Store names and pickup coordinates are sample data, explicitly labeled in the map and confirmed before opening directions.
